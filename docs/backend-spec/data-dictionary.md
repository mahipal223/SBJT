# Data dictionary

SQL Server names and definitions. SQL migrations are authoritative. `Id` is generated by SQL unless the application supplies a GUID; BusinessId is always server-scoped.

## auth.Users

Reference/control-plane; see tenant-boundaries.md.

| Column | SQL definition |
|---|---|
| Id | `uniqueidentifier NOT NULL DEFAULT NEWSEQUENTIALID()` |
| Subject | `nvarchar(200) NOT NULL` |
| Email | `nvarchar(254) NOT NULL` |
| NormalizedEmail | `nvarchar(254) NOT NULL` |

Constraints:

- `PRIMARY KEY (Id)`
- `UNIQUE (Subject)`

## app.JobItems

| Column | SQL definition |
|---|---|

| Id | `uniqueidentifier NOT NULL DEFAULT NEWSEQUENTIALID()` |
